# 智轨星云 (MatrixOS v3.0) —— 面向全自主工程 Agent 的系统级全域开发与执行规范 (P0 Blueprint)
> **适用对象**：Cursor / Claude Code / Windsurf / Devin 等全自主代码研发与系统编排 Agent
> **架构版本**：v3.0（基于苏格拉底式架构决策锁定的「18+N 群岛式独立微站 × 星轨仪器双态合体 × 全局副驾驶虫洞协议」）
## 1. 五大核心架构公理 (Locked Architectural Axioms)
1. **产品形态（Q1 锁定 · 18+N 群岛式小而精独立微站）**：
 - 彻底废除臃肿的单页 42 工具堆砌，将现存 4 大线上实机原型——ScholarMatrix (https://scholarmatrix.cc.cd)、星门 (https://xingmen-mentor.pages.dev/)、PAT-HOT (https://pat-hot.pages.dev)、预职 (https://a9b81a7031ed59d7a.app.workbuddy.host/) 解耦重构为 **18 个职责单一、拥有独立二级域名 (`*.matrixos.edu`) 与独立持久化项目台账的精品微站**。
2. **账号与数据底座（Q2 锁定 · MatrixID 全息数字孪生单点通行）**：
 - 全域共享唯一 `MatrixID` (OAuth2 + JWT) 与底层统一 `DigitalTwinAssetGraph`（PostgreSQL + pgvector 向量库 + 端侧 IndexedDB 隐私保险箱）。严禁让用户在子网站之间手动导出/导入文件。
3. **AI 交互范式（Q3 锁定 · 全局常驻统一副驾驶 + 跨站虫洞拖拽）**：
 - 18 个微站共享唯一「全局常驻 AI 副驾驶 (Global Copilot)」，支持跨站上下文记忆；在任意微站按住数据卡片拖拽，鼠标周围即刻张开全息**「Agent 跨站虫洞环 (`WormholeDropRing`)」**，松手即可携带结构化参数与 PDF 证据锚点空间翻转至目标微站。
4. **主视觉与导航形态（Q4 锁定 · 星轨引力场 + 数字精密科研仪器双态合体）**：
 - **双态合体总控台 (`orbital.matrixos.edu`)**：左侧 32% 为 2.5D 交互式 7 轨星图（环绕 18+ 动态实况微缩胶囊），右侧 68% 为折射挂载的 2~3 台数字精密科研仪器面板，底部常驻 AI Copilot 声波脉冲底座。
 - **100% 独立微站专精态 (`*.matrixos.edu`)**：点击任意仪器面板右上角 `[↗ 全屏独立打开]`，即刻进入该微站的 100% 独立定制 UI，底部声波条自动坍缩为右下角呼吸能量球。
5. **生态扩展机制（Q5 锁定 · 官方 18 旗舰微站 + MatrixOS SDK 开放插槽协议）**：
 - 核心团队维护 18 个官方旗舰微站，同时开放 `@matrixos/sdk` 与 `matrix-app.manifest.json` 标准插槽，允许各高校重点实验室挂载自研垂域微站。
